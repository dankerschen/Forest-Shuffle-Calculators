Scoring audit and limitations

Verified formulas use Lookout’s English appendix, pages 1–14, and the English rulebook. The retrieved appendix stops in the White-Footed Mouse entry. Nine formulas are therefore manual: Yellow Birch, White-Footed Mouse, White-Tailed Deer, Wintergreen, Wood Frog, Wood Thrush, Yellow-Bellied Sapsucker, Yellow Bullhead and Yellow Perch.

Manual points do not prevent entered quantities from contributing to type/species counts. Type assignments should be checked against printed symbols; this is a draft card catalog, not a complete symbol-by-symbol audit. Squirrels form their own category, not pawed animals. Common Box Turtle is counted as an amphibian as specified in the appendix example.

Basswood and Hickory use per-copy local counts. Opossums use per-copy distinct local symbols. Turkey uses a per-copy matching-symbol count because its variants cannot be identified from extracted icon text. Buckeye uses a forest-wide manually entered visible-symbol total. Rivers without fish require a separate manual count.

All named and universal rivers count once. Fish below tree-attached rivers count in forest totals. Cave cards score once on the cave and again for each Beaver. Squirrel set points appear once in the Squirrels subtotal. No external libraries, fonts, artwork or remote scripts are required.

French/German official card terminology is not yet verified or implemented. BG Stats integration is not included; CSV and JSON exports are available. Browser/device testing remains necessary.
